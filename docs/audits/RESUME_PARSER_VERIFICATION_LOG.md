### Failure Analysis:

#### Test: "should parse a valid PDF fixture buffer"
```
Error: Unable to extract text from PDF resume
Location: src/services/resumeParser.service.ts:160
```
- **Cause**: pdf-parse library cannot parse PDFs generated by pdfkit or pdf-lib
- **Evidence**: 
  - pdfkit generates valid PDF files (header `%PDF-1.7`, valid structure)
  - pdf-parse fails with "bad XRef entry" error
  - pdf-parse works correctly with Uint8Array input but fails with Buffer input
  - Root incompatibility suggests pdfkit/pdf-lib XRef structure differs from pdf-parse's expectations
- **Decision**: Document as known limitation; DOCX extraction verified as working
